Smart Tools is a simple web platform that offers helpful tools for everyday digital tasks. It includes two main tools:
1. Word Counter
A tool that instantly counts the number of words in any text entered by the user — useful for writing, editing, and tracking text/word limits.

2. Text-to-Speech Converter
A tool that converts written text into spoken audio, with the option to choose from multiple voices (different languages and accents). It’s used to improve accessibility and enable audio reading of text.
The site also includes a Feedback Form, allowing visitors to rate the site and share their comments.
The project was built using only HTML, CSS, and JavaScript, with a simple and user-friendly design
